# 版式与导航

## 全局界面

- 所有屏幕宽度统一使用页面左上角的“☰ 目录”按钮。目录为覆盖内容的左侧抽屉；点击任一 Tab 后自动收起。顶部栏中的“目的地 · 旅行手册”标题居中；不要保留桌面常驻右侧目录。
- 目录六项按固定顺序：首页、行程、住宿 / 餐厅 / 小吃、景点 / 购物 / 当地体验、检查清单、注意事项。
- 所有“查看检查清单”“查看住宿”“查看餐厅”“查看景点”“查看购物”等按钮必须真的切换到相应 Tab / 子 Tab。四个动作按钮的卡片使用 2×2 布局，更多按钮自然换行。

## 首页

免责声明 / 旅行提示横幅下必须有三张摘要卡：

1. **旅行主题**。
2. **住宿**，附“查看住宿”并跳至住宿子 Tab。
3. **优先确认**，列出核心票务 / 交通项目，附“查看检查清单”并跳至检查清单。

窄屏时三张卡自然纵向排列。

## 行程概览

- Day 切换按钮始终同一行，使用三等分列与较小间距 / 字号，不得换行到第二行。
- 每个 Day 的路线概览始终为两栏：左边是一张本地嵌入、可点击的路线示意地图；右边为纵向编号的地点清单。每一站独占一行，编号与图中 1、2、3…一一对应；绝不把节点横向串行，也不在窄屏把地图放到节点下方。
- 用图像生成制作与手册相称的无品牌旅行插画路线图。整张图链接到按相同行程顺序构造的 Google Maps 多站路线；示意图用于理解动线，实际导航以 Google Maps 为准。
