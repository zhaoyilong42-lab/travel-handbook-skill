# 验证清单

## 必做验证

1. 检查六个 Tab、日程切换、子 Tab 和抽屉的目标均存在；点击任意目录项会收起抽屉。
2. 检查每个 `data-go` / 内部跳转目标有效，酒店、餐厅、景点、购物与检查清单会进入正确子 Tab。
3. 核对所有外链：地图地点、路线顺序、官方购票、电话链接、小红书搜索词均与当前目的地资料一致。
4. 核对非离开日的返酒店卡、离开日的机场 / 车站收尾、逐条正餐与购物提及。
5. 确认每张景点卡都有 Google Maps、小红书拍照参考、上传照片、查看照片（数量）和删除当前照片；确认照片弹窗查看、桌面键盘切换、移动端滑动和删除确认，以及勾选状态和照片仅存本地浏览器。
6. 使用 Node 或浏览器检查内联 JavaScript 可解析，并在桌面和窄屏目视检查：标题、抽屉、三天按钮和“地图左 / 节点右”概览不破版。
7. 运行 `python scripts/audit_handbook.py <输出 HTML>`。脚本失败先修复结构性缺项；脚本通过后仍必须完成上述事实与交互检查。
8. 将手册“注意事项”与源攻略逐条对照：所有明确的实用贴士、避坑、安全、天气、支付、语言、紧急信息及其具体数字、时段、地点、对象或短语均已保留，或在无法确认时明确标注待确认；不得仅因版面简洁而删减。
