# 内容映射说明

## 最小输入

旅行计划 Markdown 至少应尽量提供：目的地、日期、天数、同行人数与每日行程。住宿、交通、餐厅、景点、购物、小吃、预算和注意事项可选。

## 面板映射

| Markdown 信息 | 手册位置 |
| --- | --- |
| 目的地、日期、人数、节奏、预算、住宿区域、优先预约 | 首页 |
| 每日时间、地点、路线、交通、晚餐后返程 | 行程 |
| 住宿、餐厅、小吃 | 住宿 / 餐厅 / 小吃 |
| 景点、购物点、可选体验 | 景点 / 购物 / 当地体验 |
| 交通、住宿、已选餐厅、需预约景点、证件 | 检查清单 |
| 入境、交通、安全、支付、着装、网络 | 注意事项 |

## 状态规则

- 计划明确已订或已选：显示“已选”；不要擅自写成“已预订”。
- 需要购票、预约、电话确认或尚未给出订单：显示“待确认”。
- 仅作为替补/二选一：显示“备选”或“二选一”，默认不进入检查清单。

## 缺失信息

未提供价格、电话、官网、确切地址或开放时间时，不要补写。只有“地点名 + 城市”足以可靠定位实际场地时才生成地图查询；否则标注“地点 / 集合点待确认”，不能用泛泛城市搜索替代导航。
